# yuuublog

#### 介绍
该项目以上线，可以通过访问www.yuuu.online进行查看
基于SpringBoot + vue实现的个人博客
完成登录注册、文章详情、评论发表等功能
#### 软件架构
后端采用vue-admin后台管理开源项目

#### 安装教程
本项目使用mysql8 redis6 
1.  导入项目
2.  将application中的配置信息修改为个人开发的环境
3.  启动项目
